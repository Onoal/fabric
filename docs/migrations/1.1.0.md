# Fabric v1.1.0 — Resource API Migration

**Fabric v1.1.0 is not backwards compatible with the v1.0.0 Resource operation API.**

Fabric v1.0.0 Resource operations were synchronous. Fabric v1.1.0 Resource
operations are uniformly awaitable so immediate local realizations and
event-loop-backed realizations share one capability contract.

Before:

```rust
api {
    fn get(&self, key: String) -> Result<Value, Error>;
}
```

After:

```rust
api {
    async fn get(&self, key: String) -> Result<Value, Error>;
}
```

Before call:

```rust
resource.get(key)?
```

After:

```rust
resource.get(key).await?
```

Resource self-realization operation methods become `async fn` methods. Adapter
Resource operation methods become `async fn` methods. Generated Resource
operations expose `ResourceFuture` internally, and Resource futures are not
globally required to be `Send`.

This migration changes the execution boundary only. It does not change package
semantic contracts such as KeyValue `get`, `set`, or `delete`.
