# Fabric 0.3 release candidate

Fabric 0.3 is a temporal-contract hardening release. It does not add a generic
lifecycle manager, replacement API, migration engine, recovery controller,
rollback engine, event history, or durable runtime state.

## Temporal contract

- An Instance is one generation-scoped runtime incarnation of a Composition.
- `InstanceId` is distinct from `InstanceGeneration`; every materialization
  mints a fresh, process-local generation.
- Materialization returns `Ready`; `start()` reaches `Running`; `stop()` reaches
  `Stopped`, terminal for that generation.
- `InstanceReport` is bounded current observation. Lifecycle, Health, and
  Component readiness remain distinct concepts.
- Pre-Instance materialization failure returns no usable Instance. Activation
  failure stops the same generation. Cleanup is not rollback, and retry is not
  generic recovery.
- Declaration or realization change is represented by new declarative truth and
  a fresh Instance generation. Fabric does not infer supersession, migration,
  state transfer, cutover, rollback, or replacement authority.

Compatibility for Contracts, Resource/System schemas, and Hosts means a
selection can bind or materialize. It does not prove safe replacement or state
continuity.

## Migration from 0.2

Normal Fabric 0.2 users require no lifecycle API migration for 0.3. This
release clarifies and mechanically proves the temporal contract already
expressed by the public Instance and Component boundaries. Component Adapter
realization from 0.2 remains unchanged.

## Publication status

This document prepares the Fabric 0.3 release candidate. It does not announce
that version as published to crates.io.
