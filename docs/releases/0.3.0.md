# Fabric 0.3.0

## Overview

Fabric 0.3.0 establishes open semantic augmentation and a coherent root-first
public SDK while retaining Fabric's structural and runtime foundations.

## Open semantic augmentation

Resource, System, and Component semantics may receive independently owned
augmentation. The base subject, semantic `X`, its attachment, support
implementation, and realization remain distinct. Requirements are typed and
target-bound, so consumers depend on semantic `X`, not a support provider.

Component augmentation does not rewrite the base Component operation
declaration. It contributes preparation for the same Component participation.

The public model supports third-party ownership: a base semantic crate need
not know an augmentation, and an augmentation need not know its supports.

## Root-first public API

Normal authoring uses:

```rust
use fabric::*;
```

`fabric::prelude::*` remains an optional compatibility convenience. Raw Core
machinery remains under explicit named modules.

## Experimental Projection

Projection ships under `fabric::experimental::projection`. It is not canonical
Core ontology and may change or be removed in a future minor release; it is
not casually changed within a 0.3.x patch line.

## Runtime foundation retained

Instances remain generation-scoped runtime incarnations. Lifecycle, Health,
and readiness are distinct bounded observations. Declarative or realization
change is represented by fresh declarative truth materialized as a fresh
Instance generation; Fabric does not infer migration, replacement authority,
state transfer, cutover, or rollback.

## Package family

The published Fabric family releases coherently at `0.3.0`:
`onoal-fabric-host`, `onoal-fabric-core`, `onoal-fabric-resource`,
`onoal-fabric-system`, `onoal-fabric-component`,
`onoal-fabric-sdk-macros`, and `onoal-fabric`.

Fabric 0.3.0 does not introduce a scheduler, placement engine, global semantic
registry, Adapter ID, Component-to-Component dependency model, or dynamic
plugin ABI.

## Install

```toml
[dependencies]
fabric = { package = "onoal-fabric", version = "0.3.0" }
```
