# Fabric 0.4.2

## Overview

Fabric 0.4.2 is a backwards-compatible correctness patch for normal
Resource/System authoring. It fixes location-dependent expansion of adaptable
definitions.

## Location-independent macro expansion

An adaptable `resource!` or `system!` definition now expands equivalently at
crate root, inside nested Rust modules, and from an external crate. Authors do
not need an artificial wrapper module for generated realization machinery.

The current normal syntax introduced in 0.4.1 remains supported: semantic
`version`, provisional defaults, omitted empty Config, and inferred Adapter
target support all continue to work.

## Boundaries

This patch changes no Fabric ontology, contract/realization semantics,
schema/version compatibility, Composition behavior, lifecycle behavior,
runtime-state behavior, or Component behavior.

The 0.4.1 crate family was published without a corresponding repository tag or
GitHub Release after this compiler defect was found. Fabric therefore moves
directly from the formal `v0.4.0` release to `v0.4.2`; no `v0.4.1` tag is
created.

## Install

```toml
[dependencies]
fabric = { package = "onoal-fabric", version = "0.4.2" }
```

```rust
use fabric::*;
```
