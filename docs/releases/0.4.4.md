# Fabric 0.4.4

Fabric 0.4.4 establishes universal Relations authoring for Resources, Systems,
and Adapters.

`relations { requires { name: Target; } }` is the first canonical relation
form. Targets may be Resources or Systems; normal compatibility is inferred
from the target's primary semantic contract, while explicit version ranges
remain available for advanced interoperability.

Relations lower through Fabric's existing typed contract resolution and bind to
runtime access under the author-owned relation name. They are distinct from
Config: Config supplies declarative creator-to-consumer choices, while a
Relation receives a capability through Composition.

This release does not redesign Components, API syntax, realization authoring,
or Fabric Core ontology.

```toml
[dependencies]
fabric = { package = "onoal-fabric", version = "0.4.4" }
```
