# Fabric 0.4.7

## Canonical Adapter realization

Fabric 0.4.7 completes the normal Resource/System realization path. A Resource
or System is a semantic subject; an Adapter is the concrete live realization
selected for one occurrence.

```rust
fabric::resource! {
    KeyValueStore {
        id: "example.key-value";
        api {
            fn get(&self, key: String) -> Option<String>;
        }
    }
}

fabric::adapter! {
    MemoryStore for KeyValueStore {
        runtime {
            fn get(&self, key: String) -> Option<String> {
                let _ = key;
                None
            }
        }
    }
}
```

The target semantic API is now the default realization contract. Normal Adapter
authoring names neither `for resource` / `for system` nor a generated
`implements` interface. Fabric derives those details, validates the target's
schema support, and exposes the selected Adapter directly through the typed
semantic API.

## Live-realization ownership

This public release also includes the source-only 0.4.6 correction: API-only
Resources and Systems are valid semantic definitions, but do not materialize
without a self realization or compatible selected Adapter. Concrete Adapter
state, lifecycle hooks, and health belong to its fresh live occurrence.

Self-realizing Resources and Systems remain supported. Configuration remains
declarative input, separate from occurrence-local state. Lifecycle remains
Fabric's existing orchestration model; Adapter hooks participate in the same
bind, initialize, start, stop, cleanup, and health behavior.

## Compatibility and non-goals

Existing explicit realization authoring remains available as the advanced form
when a semantic owner intentionally mediates between its public API and a
different lower-level implementation contract. The 0.4.7 release does not add
a scheduler, restart/recovery policy, deployment engine, health aggregation
framework, Adapter registry, or Component redesign.

Install with:

```toml
[dependencies]
fabric = { package = "onoal-fabric", version = "0.4.7" }
```
