# Fabric 0.7.0

Fabric 0.7.0 closes the live-whole boundary:

```text
Composition = complete immutable declared semantic truth
Instance    = complete current live semantic observation boundary
```

`Instance::observe()` is the normal live read model. It projects semantic
Resources, Systems, Components, realization observations, current desired
Component participation, current observed Component participation, lifecycle,
and health from the immutable Composition context plus current runtime state.
It is a snapshot, not history, not reconciliation evidence, and not a second
source of truth.

## Instance-bound Components

Canonical Component APIs now have a normal instance-bound route:

```rust
let app = instance.component::<App>()?;
app.reconcile()?;
let output = app.some_semantic_operation(input).await?;
```

Generated typed calls are bound to one Instance generation. Declaration lookup
can succeed before participation exists; invocation and control then return
bounded Component errors instead of treating declaration as live runtime.

Component desired participation and observed participation are distinct live
facts. `start()` starts the Instance lifecycle and does not reconcile
Components. Reconciliation is explicit through the high-level Component handle
or `Instance::reconcile_components()`.

## Boundaries preserved

Core remains generic structural construction machinery. Fabric semantic
observation is SDK-owned and uses raw Core observation only as live structural
input. Raw Core diagnostics remain deliberate through `instance.core().report()`.

No package model, history/evolution authority, distributed control plane,
Forge/Origin/Oracle/OXP integration, supervisor, or publication flow is part
of this release.
