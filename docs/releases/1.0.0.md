# Fabric 1.0.0 - Foundation

Fabric 1.0.0 is the technical Fabric foundation release. It freezes the public
1.x contract for declaring semantic systems, resolving them into immutable
Composition truth, preparing non-live materialization truth, and materializing
typed live Instances.

This is not the wider Fabric ecosystem launch. The ecosystem continues after
this release as packages, compositions, examples, and documentation migrate to
the published Fabric 1.0 crates.

## Foundation model

```text
Definitions / Authoring
    ↓
Fabric
    ↓
Composition
    + MaterializationProfile
    + Host
        ↓
MaterializationPlan
        ↓
Instance
    ├── semantic live world
    └── InstanceFacilities
```

## Established distinctions

Fabric 1.0.0 makes these boundaries part of the foundation contract:

- `Resource != System != Component != Adapter`
- `Composition != MaterializationPlan != Instance`
- `Config != State`
- `Component != ComponentParticipation`
- `Lifecycle != Health`
- semantic `Augmentation != InstanceFacility`
- declared truth `!=` planned truth `!=` live semantic truth `!=` live operational truth

## Public crates

The foundation release publishes these seven crates together at `1.0.0`:

- `onoal-fabric-host`
- `onoal-fabric-resource`
- `onoal-fabric-system`
- `onoal-fabric-sdk-macros`
- `onoal-fabric-core`
- `onoal-fabric-component`
- `onoal-fabric`

## Deliberately deferred

The following remain outside Fabric 1.0.0:

- generic Core semantic-world redesign;
- Forge Definition seam;
- general `MaterializationPlanner`;
- Profile-driven realization planning;
- Adapter realization graph;
- durable history;
- replanning, migration, cutover, and replacement authority;
- distributed occurrence truth.

Those are future architecture topics, not foundation-release requirements.

## Ecosystem

`Onoal/fabric-ecosystem` continues after this foundation release. Its next
step is to replace pre-1.0 Fabric git revision dependencies with the published
Fabric 1.0 crates and run the full ecosystem convergence matrix.
