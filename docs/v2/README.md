# Fabric V2 Future Architecture

This directory belongs to the long-lived `future/v2` branch.

`future/v2` is the reserved architectural future perspective for Fabric v2. It
exists so that pressures discovered while closing Fabric v1 can be recorded,
challenged, refined, and eventually converted into an implementation roadmap
after v1 is closed.

## Governance

`main` is the established current Fabric architecture.

`future/v2` is future architectural direction and unresolved v2 work.

Nothing written here overrides current Fabric v1/main merely because it is on a
future branch. Until explicitly promoted, these documents are directional and
investigatory, not normative current Fabric truth.

## What Belongs Here

- Discovered v2 laws.
- Architectural corrections intentionally deferred from v1.
- Future goals.
- Candidate ontology.
- Unresolved questions.
- Evidence that motivated those questions.
- Seams v1 should preserve.
- The eventual v2 convergence roadmap.

## What Does Not Belong Here

- Fabric v2 implementation in progress.
- Experimental code playgrounds.
- Feature dumping grounds.
- Replacement policy for `main`.
- Promises that every recorded idea will ship.

## Maturity Model

### Discovered Pressure

A real use case exposed a structural question.

### Candidate Law

A likely architectural distinction has been identified.

### Validated Direction

Multiple unrelated pressures support the distinction.

### Established V2

The direction is accepted as v2 architecture and ready for implementation
planning.

Candidate ideas must not be called canonical prematurely.

## Promotion

An idea becomes established v2 architecture only when evidence has moved it
through the maturity model and the project intentionally promotes it into a v2
roadmap or implementation checkpoint.
